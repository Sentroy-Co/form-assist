# Localization

Import `supportedLocales`, `resolveLocale`, `detectLocale`, `direction`, `loadCatalog` and `englishCatalog` from `@sentroy-co/form-assist/i18n`. The 54-entry metadata list includes a native language name and text direction. `resolveLocale` selects the first supported language in a list of preferences; unsupported and invalid tags fall back to English. It handles region variants and aliases including Chinese script and region variants. `detectLocale()` reads browser language preferences when called and safely returns English during server rendering.

`await loadCatalog(locale)` loads only the selected catalog and caches concurrent requests. English is immediately available through `englishCatalog`, including while a catalog loads. A failed catalog import also falls back to English. Each catalog has `ui` and `demo` sections; the canonical keys and types are in `src/i18n/types.ts`.

Set a component's `locale` property or `lang` attribute to choose a locale; leave it unset to use browser preferences. The UI observes browser language changes in automatic mode and exposes partial `messages` overrides for application wording. The demo language selector uses the same catalogs.

To add a locale, translate every key in a new `src/i18n/locales/<code>.ts` module, preserving the Markdown structure in `fixtureBody`. Export the object as the default and check it with `satisfies Catalog`. Add its native name, direction and explicit lazy import to `registry.ts`, then run `npm test` and the package build. Avoid HTML in message text. Key parity and nonblank messages are tested, but translations should also be reviewed by native speakers in context.

Chinese script subtags take priority over region: `zh-Hans-HK` selects Simplified Chinese, while `zh-Hant-CN` selects Traditional Chinese. Explicit locale properties and manual demo selection override subsequent browser languagechange events; returning to automatic mode reads current preferences again. `element.updateComplete` resolves after its catalog and visible labels update.

Catalogs are machine-assisted translations. Technical coverage and behavior have been verified; native-speaker editorial review is still needed. Form values and active proposals are never automatically translated or replaced when interface language changes. The demo fixture captures the language at request time.
