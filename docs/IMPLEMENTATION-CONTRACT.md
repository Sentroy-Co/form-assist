# Shared implementation contract

All agents use `.js` in relative TypeScript imports. Import source via relative paths. Do not edit other agents' owned files. Tests live in tests/<area>.test.ts. Root handles workspace config, shared types, fixtures, demo/docs and final integration. Report uncertainty; do not fabricate live-provider verification.

Core exports all types in core/types.ts and functions `validateForm(form): void`, `validatePlan(form, plan): void`, `applyPlan(form, plan, selectedPaths?): ApplyResult`, `undo(form, receipt): FormSnapshot`, `contextForModel(form): FormSnapshot`, `resolveOptions(form,resolver): Promise<FormSnapshot>`. Failures throw AssistError(code,message, retryAfterMs?). Validation uses JSON Schema 2020-12, strict pointers and final document schema. Revision is opaque, generated on apply. No DOM/Node imports. JSON equality via stable recursive comparison.

Provider interface is in providers/types.ts; export types from providers/index.ts. Server imports Provider. `createAssistantServer(config)` returns `{propose(request, context, signal?):Promise<ChangePlan>, handle(request:Request):Promise<Response>}`. Server config has forms registered by formId, connections (connectionId -> Provider), `authorize(context, action, resource): boolean|Promise<boolean>`, `getContext(request): Promise<ServerContext>`, optional limits. Export types. Browser transport POSTs ProposeRequest to endpoint; returns ChangePlan; no secret inputs.

Browser `createAssistant(options)` returns AssistantController. Options: binding: FormBinding, transport: (request:ProposeRequest,signal:AbortSignal)=>Promise<ChangePlan>, connectionId:string, model:string. Controller: `getSnapshot():AssistantState`, `subscribe(listener):()=>void`, `propose(prompt):Promise<void>`, `apply(paths?:string[]):Promise<void>`, `undo():Promise<void>`, `cancel():void`, `dispose():void`. State: status idle/generating/review/applied/error/conflict/cancelled; form, plan?, error?. Browser exports `createHttpTransport(endpoint,fetch?)`. FormBinding: `read():FormSnapshot`, `write(next:FormSnapshot,changedPaths:string[]):void|Promise<void>`, optional subscribe(listener):unsubscribe. Core validates atomically; bindings must ensure no stale writes.

UI `registerFormAssist(): void`, custom elements `form-assist-button` and `form-assist-spotlight`. Assign `.controller = AssistantController` via property; `open/close/toggle` methods. `createCredentialManager` may use separate authenticated server management API; never return saved raw secrets. UI agent may add credential editor with callback contract. Browser and UI are independent imports.

CLI accepts --config FILE default form-assist.config.json containing registered form snapshots, connection configs referencing credential environment variable names, allowed models and provider type; never secret CLI args. `--fixture` explicit demo mode may return deterministic valid plan through same validation flow. Server imports remain named; coordinate additions through root.
